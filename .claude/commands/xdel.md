# /xdel - Delegated Work

Use for a traceable single delegation with a Parent/Child record, without paying xflow planning and evaluation. For speed use `/xdo`; for an independent quality gate use `/xflow`.

- Read or create the relevant Hybrid Tree.
- Dispatch coderX once for the assigned scope.
- coderX follows the engineering skill and performs self-review.
- coderX returns a Note draft with the Change Summary; the Main Agent owns the close-out gate (mechanical checklist, <=5-line semantic gaps, user nod). Writing follows `proseX`.
- Do not trigger evaluatorX. An independent review happens only on explicit user request, as a separate review task.
- Full rules: `orchestrateX` SKILL.md.
