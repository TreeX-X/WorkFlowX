# xflow discovery

Inspect relevant modules, code, existing Tasks and fixed requirements. Identify affected boundaries, dependencies and verification paths. Separate facts from unknowns that can change scope or implementation.

Use socratesX only for unresolved user decisions; already-confirmed intent does not require another interview. Produce the Ready Summary with goal, boundaries, dependencies and verification before Task creation; resolve remaining decisions using existing authorization. Then Main Agent creates/reuses scoped Tasks with acceptance, dependencies and handoff context. Out-of-scope module changes remain explicit gaps.

This phase is not mandatory for ordinary xdo or a fully specified xdel handoff.
