# Module 07: Status Report

`xstatus` is read-only. Scan `.hybrid/` Parent and Child documents and report feature names, scopes, dependencies, statuses, and verification notes. Classify active work as `xdo`, `xdel`, or `xflow` when recorded. If `.hybrid/` is absent, report that no Hybrid Tree is active. Write to `./status-report.html` or `--output`; open unless `--no-open` is set.
